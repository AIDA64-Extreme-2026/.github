# Project Overview

AIDA64 Extreme is a comprehensive Windows system information, diagnostics, monitoring, and benchmarking utility designed for PC enthusiasts, technicians, and advanced users.

It provides detailed information about hardware and software while offering sensors, stress testing, benchmarks, and diagnostic tools for evaluating system configuration and performance.

# System Stability Test

The System Stability Test can place sustained workloads on selected system components.

It can help evaluate:

- CPU stability
- Cooling performance
- Memory stability
- Thermal behavior
- System reliability
- Overclocking configurations

Stress testing can significantly increase temperatures and power consumption. Hardware temperatures should be monitored throughout testing.

# Performance & Safety

AIDA64 itself is generally lightweight during normal system-information and monitoring tasks.

Stress tests and benchmarks intentionally create heavier workloads and can increase temperatures, fan speeds, and power consumption.

Avoid prolonged stress testing if temperatures exceed safe limits specified by the hardware manufacturer.

---

# Troubleshooting

If a sensor is unavailable or reports unexpected values, verify motherboard firmware, drivers, hardware-monitoring support, and the installed AIDA64 version.

For inconsistent benchmark results, close unnecessary background applications and use comparable system settings between tests.

Do not treat a successful stress test as a guarantee that a system cannot experience hardware or stability problems.
